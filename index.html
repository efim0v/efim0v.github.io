Mac apps for Claude Code

Two small tools I build and use every day. Brow shows how much of each Claude Code account’s limits is left. Grove runs parallel sessions across several repositories. Both are free and open source.

Brow

The 5-hour and weekly limits of every Claude Code account you have, in the MacBook notch, and when each one resets.

macOS 26 or later · Apple silicon · GPL-3.0 · also in Русский and 简体中文

Brow website Source on GitHub

Grove

A menu-bar app and command-line tool that gives each feature a git worktree of every repository, all on one branch, and moves a session to another account when a limit runs out.

macOS 26 or later · Apple silicon · GPL-3.0 · also in Русский and 简体中文

Grove website Source on GitHub
